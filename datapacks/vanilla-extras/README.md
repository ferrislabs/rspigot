# vanilla-extras

The vanilla jigsaw structures the server does not embed: abandoned camps, ancient cities, bastion remnants, trail ruins and trial chambers. Villages, pillager outposts and the non-jigsaw structures are built in.

Copy this folder into `<world>/datapacks/` to generate them again. Regenerate it from a decompiled vanilla datapack with:

```
python3 -I tools/gen_structures.py --datapack-out datapacks/vanilla-extras
```
